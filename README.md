# Подготовка к ЕГЭ

Сайт для подготовки к ЕГЭ с четырьмя разделами: математика, русский язык, информатика и физика. В каждом разделе можно писать конспекты и добавлять файлы. Всё сохраняется в браузере и остаётся на месте после закрытия сайта.

## Что умеет

- **Конспекты.** Текст пишется на листе в клетку и сохраняется сам, через полсекунды после последней правки. У каждого предмета свой список конспектов.
- **Файлы.** PDF, фото, документы и любые другие файлы. Их можно перетащить в окно или выбрать вручную, потом открыть, скачать или удалить.
- **Копия данных.** Кнопка «Сохранить копию» выгружает все конспекты и файлы в один файл, а «Загрузить копию» возвращает их обратно, например на другом устройстве.

## Запуск у себя

Откройте `index.html` в браузере. Если нужен локальный сервер:

```bash
python -m http.server 8000
```

После этого сайт откроется по адресу http://localhost:8000.

## Публикация на GitHub

1. На github.com нажмите **New repository**, назовите его `ege-prep` и создайте пустой репозиторий (без README и других файлов).
2. В папке с проектом выполните команды, подставив свой логин вместо `ВАШ_ЛОГИН`:

```bash
git init
git add .
git commit -m "Первая версия сайта"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ege-prep.git
git push -u origin main
```

3. Чтобы сайт открывался по ссылке, включите GitHub Pages: **Settings → Pages → Build and deployment**. В поле Source выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через минуту-две сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/ege-prep/`.

Обновить сайт после правок можно так:

```bash
git add .
git commit -m "Что изменилось"
git push
```

## Где хранятся данные

Конспекты и файлы лежат в памяти вашего браузера (IndexedDB), а не на GitHub и не на сервере. Из этого следует:

- На другом устройстве или в другом браузере сайт начнёт с чистого листа. Чтобы перенести данные, сохраните копию на одном устройстве и загрузите на другом.
- Если очистить данные сайтов в настройках браузера, конспекты и файлы пропадут. Периодически сохраняйте копию.
- Safari может удалять данные сайтов, которыми не пользовались около недели. На iPhone и Mac храните свежую копию.
- Копия собирается в один JSON-файл. Если файлов очень много (сотни мегабайт), браузер может не справиться, и тогда оригиналы лучше хранить отдельно.
- Копии содержат ваши личные материалы, поэтому они добавлены в `.gitignore` и не попадут в репозиторий.

## Структура проекта

```
index.html   разметка страницы
style.css    оформление
app.js       вся логика: предметы, конспекты, файлы, хранение
```

Сборка не нужна: это обычные HTML, CSS и JavaScript без зависимостей. Шрифты (Golos Text и Marck Script) подгружаются с Google Fonts, а без интернета сайт использует системные шрифты.
